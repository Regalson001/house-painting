# 🏠 House Painting — HTML & CSS Project

A clean, visually appealing house illustration created using **HTML5 and CSS3**. This project demonstrates how fundamental web technologies can be used to build simple graphics, arrange visual elements, and create a responsive layout without relying on images or JavaScript.

## 📌 Project Overview

The House Painting project recreates a simple house using HTML elements styled entirely with CSS. It features a triangular roof, painted walls, windows, a door, a chimney, and a ground detail.

The project focuses on strengthening front-end development fundamentals through element positioning, color selection, geometric shapes, borders, and responsive styling.

## ✨ Features

- **CSS-built house illustration** — Constructed using HTML elements and CSS styling.
- **Custom roof design** — A triangular roof created with `clip-path`.
- **Detailed house structure** — Includes walls, chimney, windows, and a door.
- **Decorative details** — Features window divisions, a door handle, and ground styling.
- **Modern layout** — Uses CSS Grid to center the illustration on the page.
- **Responsive adjustments** — Includes a media query for smaller screens.
- **Clean visual design** — Combines warm house colors with a soft background.
- **No JavaScript required** — The illustration is built using HTML and CSS alone.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Defines the structure and elements of the illustration |
| CSS3 | Controls colors, shapes, dimensions, and positioning |
| CSS Grid | Centers the illustration within the viewport |
| CSS Positioning | Arranges individual house components |
| CSS `clip-path` | Creates the triangular roof |
| CSS Pseudo-elements | Adds decorative details to the door |
| Media Queries | Adjusts the layout for smaller screens |
| Git & GitHub | Version control and project hosting |

## 🚀 Getting Started

### Prerequisites

You only need:
- A modern web browser.
- A code editor such as Visual Studio Code (optional, for editing).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Regalson001/house-painting.git
   ```

2. Open the project folder:

   ```bash
   cd house-painting
   ```

3. Open `index.html` in your browser.

   Alternatively, open the folder in Visual Studio Code and use the Live Server extension to preview the project.

## 🎨 Design Details

The illustration uses a simple architectural structure and a warm color palette.

- **Background:** Soft blue-gray.
- **Walls:** Warm light beige.
- **Roof:** Terracotta red.
- **Windows:** Light blue with dark frames.
- **Door and outlines:** Dark brown.
- **Ground:** Soft green.

The design uses relative sizing, layered positioning, and borders to create the appearance of a small house.

## 📱 Responsive Design

A CSS media query adjusts the illustration on smaller screens. The house uses a viewport-relative width to help it fit different screen sizes.

The project is a beginner-level responsive illustration rather than a complete responsive website.
